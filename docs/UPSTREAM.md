# Upstream

TeraBox-SIN is a fork of `seiya-npm/terabox-api` and preserves its MIT license,
history, and attribution. The fork adds secure local authentication storage,
agent tooling, CLI and MCP integration while retaining the complete public
`TeraBoxApp` method surface.

Upstream remote:

```text
https://github.com/seiya-npm/terabox-api.git
```

Recommended local remotes:

```bash
git remote add upstream https://github.com/seiya-npm/terabox-api.git
git fetch upstream
git merge upstream/package
```
